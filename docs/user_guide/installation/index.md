# Installing AWS Deadline Cloud for Blender 

To install the AWS Deadline Cloud for Blender submitter, you will need:

- A Windows, MacOS, or Linux workstation
- Blender 3.6 or later
- [Deadline Cloud monitor](https://docs.aws.amazon.com/deadline-cloud/latest/userguide/monitor-onboarding.html)
- Access to an AWS Deadline Cloud farm with either
    - a service-managed fleet, or
    - a customer-managed fleet with Blender and the Blender adaptor set up

There are two ways to install the Deadline Cloud for Blender submitter:

- [Using the Deadline Cloud submitter installer](installation.md) (recommended)
- [Installing the submitter from Blender](enable-addon.md)
